# miqaat

A single page that helps people add the Anjuman-e-Burhani New Jersey miqaat
calendar to their phone.

It exists because the calendar link Google generates does not survive being
shared. WhatsApp will not turn a `webcal://` address into something tappable,
and the Google Calendar app cannot add a calendar on a phone, so one link does
not work for everyone. This page gives each platform the route that works for it.

Published at <https://shahzadabbas-personal.github.io/miqaat/>.

The calendar itself, and the tooling that keeps its timings current, live in a
separate repository. Nothing here does anything beyond linking to a calendar that
is already public.
